# Apartment App Reference UI

This package is provided as a visual and functional reference for the Apartment Management project. It is not the final mobile application.

## Target delivery model

- Android and iOS: React Native with Expo
- Super Admin web console: Next.js
- Backend API: Node.js with Express
- Database: MySQL on Hostinger for staging/production, unless an approved external PostgreSQL service is selected
- Source control: company GitHub organization

Use the existing UI to understand the intended modules and interaction patterns. Preserve useful design decisions, but do not force desktop layouts into the mobile app.

All sample records are synthetic. Do not add production credentials or real resident data to the repository.
